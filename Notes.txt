2 Types of Errors in Full-Stack Applications
1)Validation Errors
Occur when input data is incorrect or incomplete
Example:
Required field missing
Invalid email
Wrong data type


2)Database Errors
Caused by MongoDB or Mongoose
Connection failure
Duplicate key
Schema violation
Query failure
3)Server / Backend Errors
Caused by Node / Express
Wrong route
Server crash
Exception not handled
4)Frontend Errors
Caused in React
API call failure
UI crash
State issues
